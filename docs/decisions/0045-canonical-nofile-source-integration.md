Status: accepted test-only source integration; final-source and native qualification pending.

## Context

are prepared source at feature parent `fcb0a336d02fececa39c927de2ab89de5cffe984`.

## Decision

Append exactly one nofile child as canonical invocation 28, after the original
27 calls and immediate successful PIDs27 reader. Use a separate one-child
`native_conformance_outer_v1` owner scope. Register only the existing exact
ignored library test in the canonical wrapper and forward the wrapper's
once-created deadline without renewal. Retain the producer's cleanup reserve,
eight-slot known-ID guard, one-shot handoff and private-output budgets. Reuse
bounded raw wrapper capture and export only closed nofile stage markers and
allowlisted numeric source locations; never native private payloads.

Always run the existing 12-fact reader immediately, including without public
emission. Bind its expected context and selected outer backend independently
from harness facts. Repeat that validation in the existing 19-argument emitter,
requiring precisely the typed three-key nofile-v1/empty-capability/false-catalogue
result before constructing or writing output. Add no public nofile field,
capability, schema or catalogue grant. Finite effects cannot admit Ulimits or
UlimitNofile without the required finite and unlimited source shapes.

Preserve truthful finite, exact-unlimited, finite-normalized and specifically
attributable known-ID start-refusal outcomes. Unknown ID, generic failure,
uncertain ownership/cleanup, malformed proof or exceeded bounds fails the lane.
The original lane EXIT cleanup and fresh aggregate remain required. Strict
rootless PIDs/delegation and hosted-runtime prerequisites cannot be bypassed.

## Consequences

This supersedes only prepared/unwired nofile statements in current docs and
ADR 0041's later-integration statement. All PIDs authority, witness, typed-v2,
accounting, source/read/custody and cleanup requirements remain. Historical
26/27-call evidence remains immutable and does not qualify this changed source.
The old runtime/broker/application overlay remains separately preserved and is
not subsumed or activated by this seam.

Independent meaningful order/refusal/deadline/context/backend/privacy and
unchanged-emission controls, final-edit complete gates and fresh exact-candidate
four-lane 28-call native evidence remain required. Source/synthetic checks are
not native compatibility, application acceptance, release or publication proof.
No product API, runtime operation, image/tool/dependency pin, shared workflow,
resource budget or Renovate ownership/location changes. Record six-repository
consumer and pin-extraction no-change evidence with the implementation.
