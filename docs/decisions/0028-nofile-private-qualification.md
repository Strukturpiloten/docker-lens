# ADR 0028: Mandatory nofile private qualification

Status: accepted source-only integration; fresh native qualification pending.

## Context

ADR 0027 requires PIDs private qualification as canonical invocation 27 without
public PIDs projection. The prepared nofile producer and strict reader already
define eight CLI/rendered fixtures with precise finite effects, attributable
known-ID unlimited-start refusal, finite kernel normalization and exact-unlimited
dispositions. Preparation, compilation and synthetic proofs are not native
qualification or admission. Existing Ulimits/UlimitNofile groups still require
their complete finite and unlimited source shapes.

## Decision

Append `native_nofile live_nofile_limits_and_effects_match_engine` as invocation
28, selecting the existing private library test
`native_health_metadata_tests::lifecycle::nofile::live_nofile_limits_and_effects_match_engine`.
Keep the first 27 calls/order and all five earlier cleanup-owner blocks byte-exact.
Give only the new child the existing authenticated outer-cleanup token in its own
one-child subshell. Exact single ignored-test selection, numeric-summary success,
original native exit diagnostics and fail-closed handoff behavior remain mandatory.
A cleanup-unverified or authenticated handoff marker fails even beside a passing
numeric summary; a handoff request never proves outer cleanup completed.

Pass the wrapper's original once-created 180-second deadline through
`NATIVE_NOFILE_DEADLINE_EPOCH`, without reset or budget expansion. Preserve
the 46-second cleanup reserve, 72 cleanup captures, once-only ownership guard,
eight fixture outcomes and all producer/reader/private protocol behavior.
Only the leading producer documentation comment changes registration status.
The scoped nofile proof allowance remains 512 KiB, with separately bounded 64 KiB
metadata; other private proofs retain their 16 KiB default. This changes no
ordinary capture/stdout/stderr, request, task, acquisition or transport limit.
Actual 8192-byte inspect output fit and native timing remain empirical obligations.

Bind fixed direct child `nofile-v1.json` to independently derived harness context.
Always execute the existing twelve-argument CLI reader after the child and before
the optional public-emission block, including runs without emission. Preserve the
nineteen-argument emitter ABI; it independently requires the existing reader on
that fixed child using the existing external context before output. Require
exactly typed keys `contract`, `capability_admission`, `catalogue_admission`
with values `nofile-v1`, `[]`, `false`. Integer zero is not Boolean false.
The proof's scope remains internally validated; it is not a fourth return key.
Missing, malformed, cross-context, partial, effect, cleanup, custody or return
failures refuse the entire public output.

Add no public nofile projection, fields, capability/shape mapping, schema change
or catalogue admission. Raw counts stay Debian 43/66 and upstream 45/70; selected
counts remain 34/56 and 36/60. Historical receipts and ADRs remain unchanged.
Never relabel unexpected unlimited failures as unsupported to obtain qualification.
Diagnostics admit only actual nofile context/effects/capture/cleanup/proof stages,
existing shared context/cleanup/handoff markers and first-panic allowlisted numeric
locations, not secrets, raw paths or invented stages.
