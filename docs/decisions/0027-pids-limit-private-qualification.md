# ADR 0027: Mandatory PIDs private qualification

Status: accepted source-only integration; fresh native qualification pending.

## Context

ADR 0026 requires 26 canonical invocations and raw projection totals of Debian
43 capabilities/66 shapes and upstream 45/70. ADR 0022 independently selects
reviewed lifecycle envelopes at 34/56 and 36/60. The prepared `pids-limit-v1`
producer and strict reader already implement finite 16/64 and bounded unlimited
controls. Their existence, compilation and synthetic tests do not prove native
effects or admit product support.

## Decision

Append `native_pids_limit live_pids_limit_effects_match_engine` as invocation 27,
selecting the existing private library test
`native_health_metadata_tests::lifecycle::pids_limit::live_pids_limit_effects_match_engine`.
Preserve the first 26 calls/order, original six-child owner block, and all three
earlier one-child owner blocks byte-exact. The new child alone receives the
existing lifecycle outer-cleanup owner token in a separate subshell. Preserve
original nonzero status, exact single-test listing and numeric-summary checks.
Cleanup-unverified or authenticated outer-handoff markers force failure even
beside an apparently passing summary; requesting handoff is not verified cleanup.

Pass the wrapper's once-created 180-second deadline through
`NATIVE_PIDS_LIMIT_DEADLINE_EPOCH`; do not reset it or enlarge any parent, command,
byte, task, acquisition or cleanup limit. The 46-second cleanup reserve, existing
producer/reader, shared bounded custody and 16 KiB private proof maximum stay
unchanged. The PIDs producer emits no PIDs-specific stage markers. Diagnostics
therefore expose only existing shared context/cleanup/handoff markers and the
first panic's allowlisted numeric source location (`native_pids_limit_tests` or
the existing shared basenames), never arbitrary stages, payloads or private paths.

Bind the fixed direct child `pids-limit-v1.json` to the independently derived
harness candidate and existing context. Always execute the existing twelve-argument
PIDs CLI reader before the optional public-emission block, including runs without
public emission. Keep the emitter's nineteen-argument ABI unchanged. Before any
output, it independently reads that fixed child against its existing external
context and requires exactly typed keys `contract`, `capability_admission`,
`catalogue_admission`, `scope`, with values `pids-limit-v1`, `[]`, `false`, and the
existing reader's `SCOPE`. Missing, malformed, partial, cross-context, effect,
cleanup, custody or return-contract failures refuse the entire output.

This is mandatory private positive qualification, not raw PIDs projection.
Add no public PIDs fields, capability/shape mappings or schema definitions.
Raw totals remain Debian 43/66 and upstream 45/70; selected catalogue totals
remain 34/56 and 36/60. Catalogue and historical records remain unchanged.
Nofile remains privately registered/compiled only, outside the canonical 27;
host capture remains deferred. This decision does not change product APIs,
renderers or native protocol behavior.

## Consumers and validation

Local `scripts/native-conformance.sh`, main-push `.github/workflows/check.yml`,
trusted-main dispatch `.github/workflows/native-validation.yml`, and
`.github/workflows/release-validation.yml` share the same canonical harness.
No workflow, operational pin or dependency definition changes. Verified unchanged
Renovate ownership: `renovate.json`'s custom regex manager extracts the five image
references in `scripts/native-conformance.sh`, grouped as native images with
automerge disabled. No extraction path or value moves, so no manager change is
needed. The other Lens libraries and the website do not consume this Docker-native
harness. BoxFerry owns its separate consumer and application gates; no Lens product
depends on BoxFerry. The existing dependency-policy distinction remains valid.

Focused mocked/source-only tests check ordering, ownership, exact selection,
deadline, diagnostics, independent proof custody and whole-output refusal, plus
unchanged four-lane synthetic projection counts. These checks and definitions
are not native evidence. The primary still owns the complete final-edit gates,
fresh exact-candidate four-lane 27-test qualification (108 invocations), independent
review and all actual consumer/release obligations. Historical receipts remain
historical; this integration does not qualify the changed candidate.
